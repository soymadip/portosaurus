It serves as the single source of truth for:

- **Guides**: Step-by-step tutorials and getting-started content.
- **Reference**: In-depth API and configuration documentation.
- **Blog**: Release notes, changelogs, and announcements.

## Repository Structure

- `config.yml` — The configuration for the site.
- `docs/` — Markdown/MDX source files for the documentation.
- `blog/` — Release notes and other blog posts.
- `static/` — Static assets like images and diagrams.

## Local Development

If you'd like to explore or contribute to the docs:

1. **Clone the repository:**

   ```bash
   git clone {{clone_url}}
   cd {{repo_name}}
   ```

2. **Start the development server:**

   ```bash
   bun install
   bun run dev
   ```
